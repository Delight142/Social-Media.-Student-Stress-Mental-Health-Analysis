# Social Media, Student Stress & Mental Health Analysis

## Project Overview
This project explores how social media usage influences students' stress levels, mental health, study habits, sleep duration, and physical activity. Using Microsoft Excel, I cleaned, analyzed, and visualized the dataset to identify behavioral patterns and provide actionable insights.

## Dataset Source
This project uses the "Student Social Media & Mental Health Impact" dataset sourced from Kaggle
- <a href= "https://www.kaggle.com/datasets/shivasingh4945/student-social-media-and-mental-health-impact" >Link to dataset;

## Questions
- How does daily social media usage affect students' mental health?
- Which social media user group experiences the highest stress?
- Does sleep duration influence stress levels?
- How does physical activity relate to mental health?
- Which social media platforms are associated with higher stress levels?
- What are students primarily using social media for?
- How do different purposes of social media usage impact stress?
- How much time do different user groups spend studying?
- Are heavy social media users more likely to report poorer mental health?
- How do stress levels vary across different countries?

  ## Process
- Data Collection – Obtained the dataset from Kaggle.
- Data Cleaning – Checked for missing values, removed duplicates, standardized data, and ensured consistency.
- Data Preparation – Organized the data and created Pivot Tables to summarize key metrics.
- Data Analysis – Analyzed relationships between social media usage, stress levels, mental health, sleep, study hours, physical activity, and platform usage.
- Dashboard Development – Designed an interactive dashboard using Pivot Charts, Slicers, and Excel formatting to visualize key insights.
- Insight Generation – Interpreted trends and summarized findings to answer the project's key business questions.

## Final Conclusion

This project demonstrates how Microsoft Excel can be used to transform raw data into meaningful insights through data cleaning, analysis, and interactive visualization. The findings suggest that higher social media usage is generally associated with increased stress levels and lower mental health scores, while healthy habits such as adequate sleep and regular physical activity are linked to better mental well-being. Additionally, the analysis highlights that the purpose and intensity of social media use can influence students' stress levels more than the choice of platform itself.

Overall, this project strengthened my skills in data cleaning, exploratory data analysis (EDA), dashboard design, and data storytelling using Excel. It also reinforced the importance of using data to uncover patterns that can support informed decisions and encourage discussions around student mental health.
